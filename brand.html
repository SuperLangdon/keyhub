LEOBOG ONE 键盘网页驱动 · 非官方开源复刻

概念 · 键帽 Hub

KeyHub 是键盘驱动，最诚实的符号就是一颗键帽 —— 名字本身就是标志。

  • 横标（大空间）：墨色 Key + 藏在橙色键帽里的墨色 Hub。键帽是唯一的图形隐喻 —— 我们驱动的对象就是一颗颗键帽，不要另造。
  • 方标（小空间）：墨色圆角方 tile，上行 Key、下行橙色键帽 Hub，即 app icon。自带底色，浅底深底通用。
  • 小尺寸（favicon ≤32px）：简化为「橙色键帽 + 粗体 H」剪影，保证标签页可辨认。
  • 名字 = Key + Hub。永远写 KeyHub，不写 Keyhub / keyhub / KEYHUB（全大写仅限图形化场景）。
  • 字母是手工构建的等线几何体（圆头笔画，K/e/y/H/u/b），不依赖任何字体文件；正文与界面仍用 Inter / JetBrains Mono。

标志

方标自带墨色 tile，任何底色直接使用；侧栏等应用内嵌位置用内联版（tile 与 Key 字色走 CSS 变量，随日/夜主题自动切换）。

mark.svg · 方标（任意底色）
mark.svg · 深底同样成立
favicon.svg · 小尺寸简化（橙键帽 + H）

侧栏用法（index.html）：内联 mark-inline.svg 的内容，tile 用 var(--mark-tile)、Key 用 var(--mark-key)、键帽用 var(--primary) —— 深色主题下 tile 自动提亮为 #3a3830，与画布拉开层次。推荐尺寸 38px（侧栏 64px 栅格内）。

横标

大空间（欢迎页门禁、README、og 图）用横标；Hub 藏在键帽里是唯一橙色元素，其余字母用墨色。深底换用 -dark 变体（Key 提亮、橙提亮）。

用法

  • 要：小空间（侧栏、标签页、头像位）用方标，大空间（欢迎页、文档头、分享卡）用横标 —— 不要把横标塞进 40px 的格子。
  • 要：橙色保持稀缺 —— 每个构图里只有键帽是橙色的；深色底一律换用 -dark / 内联变体。
  • 要：应用内嵌 UI 用内联 SVG + CSS 变量（tile/字色随主题），不要贴死色的 <img>。
  • 不要：给标志加投影、渐变、描边光环 —— 深度只靠色块与墨色对比。
  • 不要：改变键帽圆角比例、拉伸变形、给键帽换颜色或把 Hub 拆出键帽。
  • 不要：引入第二个强调色或给非键帽元素上橙色。

资产与再生成

所有品牌资产由零依赖脚本生成，不要手改 assets/brand/ 下的文件（侧栏内联 SVG 是 mark-inline.svg 的拷贝，重新生成后需同步粘贴）。

node tools/gen-brand.mjs # 生成全部资产（assets/brand/ + favicon.* + apple-touch-icon） node tools/gen-brand.mjs --preview # 仅输出目检大图 tools/preview-brand.png node tools/gen-brand.mjs --crops # 字形 / 像素级检查图 tools/preview-crops.png

字形几何（K/e/y/H/u/b 笔画、字距、键帽内衬、方标竖排节奏等）都在 tools/gen-brand.mjs 顶部的 glyphsAt / PAIR_GAP / WIDE / MK / FAV 常量里调。
